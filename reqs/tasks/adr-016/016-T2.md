# [TDD] GitHubAdapter: フェーズラベル定義の拡張とパターン認識の追加

## 1. 目的と背景 (Goal & Context)

- **As-is (現状)**: 現状の `GitHubAdapter` は `adr:(\d{3})` のみを動的ラベルとして認識し、フェーズ関連のラベル定義を持っていない。
- **To-be (あるべき姿)**: `GitHubAdapter` が `design:XXX` ラベルを認識し、さらに新規フェーズラベル (`arch`, `spec`, `tdd`, `plan`, `audit`) の属性（色、説明文）を保持している。
- **Design Evidence (設計の根拠)**: ADR-016 「ADR Phase Transition Automation」 4.3. ラベル置換機能

## 3. 実装手順と制約 (Implementation Steps & Constraints)

### 3.1. 負の制約 (Negative Constraints)

- [ ] **変更禁止**: `IGitHubAdapter` の既存のメソッドシグネチャは変更しない。
- [ ] **スコープ外**: GitHub API への実際のリクエスト発行部分は既存の実装を流用し、本タスクでは属性定義に集中する。
