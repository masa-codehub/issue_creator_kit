# 1. Goal & Context

## SMART Goal

`GitHubAdapter` において、フェーズラベル (`arch`, `spec`, `tdd`, `plan`, `audit`) の属性（色、説明文）を定義し、`ADR_LABEL_PATTERN` を拡張して `design:` プレフィックスにも対応させる。

## As-is

現状の `GitHubAdapter` は `adr:(\d{3})` のみを動的ラベルとして認識 し、フェーズ関連のラベル定義を持っていない。

## To-be

- `GitHubAdapter.LABEL_ATTRIBUTES` に `arch`, `spec`, `tdd`, `plan`, `audit` を追加する。
- `GitHubAdapter.ADR_LABEL_PATTERN` を `(adr|design):(\d{3})` に拡 張し、両プレフィックスに対して正しい属性（説明文）を返す。

## Design Evidence

- `reqs/design/_approved/adr-016.md`
- `reqs/context/adr-016/context-map.md`

# 2. Input Context

- `src/issue_creator_kit/infrastructure/github_adapter.py`
- `tests/unit/infrastructure/test_github_adapter.py`

# 3. Implementation Steps & Constraints

## Steps

1. `tests/unit/infrastructure/test_github_adapter.py` に、`design:` ラベルと新規フェーズラベルに対する `_get_label_attributes` のテス トケースを追加する（Red）。
2. `GitHubAdapter.LABEL_ATTRIBUTES` に以下の定義を追加する：
   - `arch`: `{color: "0e8a16", description: "Architecture design phase"}`
   - `spec`: `{color: "fbca04", description: "Detailed specification phase"}`
   - `tdd`: `{color: "1d76db", description: "Test Driven Development (implementation) phase"}`
   - `plan`: `{color: "d4c5f9", description: "Planning stage"}`
   - `audit`: `{color: "d93f0b", description: "Audit required / Quality gate"}`
3. `ADR_LABEL_PATTERN` を `re.compile(r"^(adr|design):(\d{3})$")`  に更新する。
4. `_get_label_attributes` において、`design:` の場合も適切な説明文を返すように調整する。
5. テストを実行し、パスすることを確認する（Green）。

## Constraints

- 既存の `L1` ラベルや `adr:XXX` ラベルの定義を壊さないこと。
