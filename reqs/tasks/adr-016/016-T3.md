# [TDD] RelayEngine: integration タスク完了時の上位 Issue フェーズ遷移ロジックの実装

## 1. 目的と背景 (Goal & Context)

- **As-is (現状)**: 現状の `RelayEngine` は下位のタスク更新のみを担当しており、上位 Issue へのフィードバックやラベルのフェーズ遷移機能を持っていない。
- **To-be (あるべき姿)**: `RelayEngine` が `integration` + `audit` タスクの完了を検知し、上位 Issue のラベルを `arch` -> `spec` -> `tdd` の順序で安全に遷移させる。また、古いフェーズへの巻き戻りを防ぐ冪等性ガードを実装する。
- **Design Evidence (設計の根拠)**: ADR-016 「ADR Phase Transition Automation」 4.4. フェーズ遷移ロジック
